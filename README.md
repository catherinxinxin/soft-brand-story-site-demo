# Soft Brand Story Site · Public Demo

这是一个固定布局、柔和渐变和叙事滚动效果的品牌官网视觉演示。

## 演示内容

- 产品家族切换与卖点展示
- 安心旅程卡片横向交互
- 用户实证图片跟随鼠标的轻微视差效果
- 鹤小飞一家 IP 卡片交互
- 星妈会与会员等级区域

页面中的品牌名、产品、IP、图片和消费者证言均为虚构示例，仅用于视觉演示，不代表任何真实品牌或产品功效。

## 本地预览

在当前目录运行：

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。
